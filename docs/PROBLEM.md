# Chat & Community

## Problem

People need one place to communicate privately with friends and
participate in shared community discussions.

## Goals

- Support user accounts and profiles.
- Enable one-to-one conversations.
- Send and receive text messages in real time.
- Display conversation history.
- Create and participate in communities.
- Support community discussions and membership.
- Provide a foundation for future notifications and media sharing.

## Initial Scope

Start with user profiles, private conversations, text messages,
and basic communities.

Do not add voice calls, video calls, or complex moderation tools
to the initial version.

## Platforms

- iOS
- Android

## Development Workflow

1. Problem and requirements
2. Data models and business logic
3. Authentication and authorization
4. Persistence and real-time messaging
5. UI and navigation
6. Testing and release preparation

## Initial Design Decisions

- Use Expo and React Native with TypeScript.
- Use Expo Router for file-based navigation.
- Keep the initial implementation small and incremental.
- Decide on the backend after defining the data models
  and security requirements.
